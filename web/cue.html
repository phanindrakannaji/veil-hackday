Setup · Before you start

  1. Mac Terminal: Veil server running · keep that window open
  2. Console → Start clean demo (or Wipe everything)
  3. Mac /camera · iPhone /pass · iPad /console · this tab /cue
  4. QR scanning is automatic when camera is live (or drag INTERNAL box onto your face)

Stack · Neo4j · Crusoe · OpenRouter

  • Neo4j — Media Rights Graph (Person/Pass/Clip + CAPTURED/EXPORTED); memory fallback if down.
  • Crusoe — primary LLM for Explain, Consent brief, Revoke impact narrative (fast flash model).
  • OpenRouter — fallback if Crusoe fails; multi-model Judge panel in parallel.

Judge Q&A · Veil

  • "Is that face AI / biometric ID?" — No. Phone is the Pass (QR credential). Station enrolls Pass → face geometry (MediaPipe detection, not recognition). Unbound faces → public blur. Identity = Pass bind, not face database.
  • "How do crowds work?" — Each person needs their own Pass (2nd phone or Console Issue). Camera auto-scans each QR → binds to best unbound face. One Pass per person.
  • "What if they leave and come back?" — Face tracker (geometry) follows in-frame. Pass stays bound per-person for that session. Revoke Pass → instant deny for that person.
